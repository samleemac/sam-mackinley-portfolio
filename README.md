# Sam MacKinley — Portfolio

Static single-page portfolio site. No build step required.

## Local preview

Open `index.html` in a browser, or run:

```bash
npx serve .
```

## Deploy on Vercel

1. Push this repo to GitHub.
2. In [Vercel](https://vercel.com), import the repository.
3. Leave the framework preset as **Other** (static site).
4. Deploy — Vercel serves `index.html` from the project root.

Project videos and posters live in `media/`.
